# ReserveChain.io — Existing Website Review

Reference reviewed: https://reservechain.io/ (public homepage as viewed on 2026-10-09)

## What the existing site already communicates
- ReserveChain positions itself as real-world asset / industrial-metals tokenization infrastructure.
- It features Ultrafine Copper Powder and Ultrafine Nickel Wire as initial programs.
- Navigation already groups platform, assets, enterprise, investors, company and legal/resource areas.
- It presents a physical-to-digital workflow, a Digital Asset Passport preview, and a Proof-of-Reserves section.
- It includes a pre-launch disclosure and links to legal/documentation pages.

## Important scope conflict to resolve before production
The live homepage currently includes “Buy Token” calls to action and describes a purchase path, a token role, and physical redemption mechanics. The supplied Final Master Developer Instructions v2.0 require the public pre-launch website not to present an active token sale, token purchase, wallet/payment flow, or redemption service unless the required approvals have been supplied and the relevant functions expressly authorised. This demo follows the supplied master instructions and therefore keeps sale, wallet, payment, tokenization, reserve, custody, and redemption functions inactive.

This is a requirements conflict to raise with the project owner; do not silently change the live production site or claim the legal position is resolved. The project owner and legal reviewer must confirm which approved version governs production publication.

## Demo direction
- Preserve the institutional ReserveChain identity and dark navy / graphite / copper / gold / silver visual system.
- Explain the infrastructure layer rather than presenting the project as a generic crypto presale.
- Treat supplied IGAS sample analysis images as source documents only, not proof of current inventory, ownership, custody, insurance, valuation, or reserves.
- Make the Digital Asset Passport explicitly illustrative.
- Keep the waitlist as registration of interest only and state that this front-end form does not send data to a server.

## Scope status
This folder is a static front-end contest prototype. It is not a WordPress CMS or production backend, and it does not implement secure authentication, email verification, a database, tamper-evident audit logs, smart contracts, mobile apps, or production integrations.
